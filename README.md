One excuse line for make.fun's "The Excuse That Almost Works" bounty. `main.ts` writes a single 106-character, 19-word excuse to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–140 characters, one line, max 20 words, not only whitespace) before writing.
